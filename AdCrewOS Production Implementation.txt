  1GgAdCrewOS Production Implementation Plan
Project Overview
AdCrewOS is a SaaS platform for small business owners, freelancers, small agencies, and solopreneurs to autonomously manage ad accounts across Google Ads and Meta (Facebook) Ads through a unified dashboard with alerts, reporting, and automated spend management.

Key Requirements
Pricing Tiers:
Solo: $49/month + 2% of ad spend
Agency: $199/month + 1% of ad spend
Free Trial: 7 days
Payment: Stripe/PayPal integration
Core Features:
Unified dashboard
Real-time SMS/Email alerts
Downloadable scheduled reports
3-step easy onboarding
Auto-pause/increase spend based on thresholds
Domain: AdCrewOS.com
Brand: Dark theme, cyan/turquoise accents

API Endpoints (High-Level)
Authentication
POST /auth/register - User registration
POST /auth/login - User login
POST /auth/refresh - Refresh JWT
POST /auth/logout - Logout
POST /auth/oauth/google - OAuth callback
POST /auth/oauth/meta - OAuth callback
Ad Accounts
GET /ad-accounts - List connected accounts
POST /ad-accounts - Connect new account
DELETE /ad-accounts/:id - Disconnect account
GET /ad-accounts/:id/campaigns - Get campaigns for account
GET /ad-accounts/:id/metrics - Get account metrics
Campaigns
GET /campaigns - List campaigns
GET /campaigns/:id - Campaign details
PATCH /campaigns/:id - Update campaign settings
GET /campaigns/:id/performance - Performance data
Alerts
GET /alerts/config - Get alert configuration
POST /alerts/config - Create/update alert rules
GET /alerts/history - Alert history
PATCH /alerts/:id/status - Mark alert as read
Reports
GET /reports - List scheduled reports
POST /reports - Create scheduled report
DELETE /reports/:id - Delete report schedule
GET /reports/:id/download - Download report
Billing
GET /billing/subscription - Current subscription
POST /billing/upgrade - Change tier
GET /billing/invoices - Invoice history
POST /billing/payment-method - Update payment method
Team (Agency tier)
GET /team/members - List team members
POST /team/invite - Invite team member
DELETE /team/members/:id - Remove member

Database Models (Prisma)
// User & Auth
- User (email, password, tier, trialEndsAt, subscription)
- OAuthToken (userId, provider, accessToken, refreshToken, expiresAt)
- Session (userId, token, expiresAt)

// Billing
- Subscription (userId, tier, status, currentPeriodStart, currentPeriodEnd)
- Invoice (userId, amount, status, paidAt)
- AdSpendTracker (userId, month, totalSpend, percentCharged)

// Ad Accounts
- AdAccount (userId, provider, externalId, name, status, currency)
- AccountPermissions (userId, adAccountId, role)

// Campaigns
- Campaign (adAccountId, externalId, name, status, budget, performance)
- CampaignMetric (campaignId, date, spend, impressions, clicks, conversions, revenue)

// Alerts
- AlertRule (userId, type, metric, threshold, action, enabled)
- Alert (userId, type, message, status, createdAt)
- AlertNotification (alertId, channel, status, sentAt)

// Reports
- Report (userId, name, metrics, schedule, format)
- ReportGeneration (reportId, generatedAt, fileUrl)

// Team
- TeamMember (organizationId, userId, email, role)
